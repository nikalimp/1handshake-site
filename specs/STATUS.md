### DNS 1handshake.com (reg.ru) — план на день запуска
1. Vercel → проект `1handshake-site` → Settings → Domains → добавить `1handshake.com` и `www.1handshake.com` (если корень сейчас привязан к проекту app — сначала убрать его там; `app.1handshake.com` не трогать).
2. reg.ru → DNS-зона, записи — **ровно те, что покажет Vercel**; обычно: `A  @  →  76.76.21.21` (или новый IP, который покажет Vercel), `CNAME  www  →  cname.vercel-dns.com.`; `CNAME  app  →  cname.vercel-dns.com.` уже есть — не менять. NS остаются reg.ru.
3. Если корень уже смотрит на Vercel — DNS не меняется вообще, только перенос домена между проектами в Vercel.
4. Проверка: SSL выпущен, `1handshake.com` — сайт, `1handshake.com/@<handle>` — визитка со стилями, вход в app работает.
